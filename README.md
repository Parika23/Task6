# NumPy Numerical Data Analysis

## Overview

This Google Colab notebook demonstrates the use of **NumPy** for numerical data analysis. It focuses on fundamental array operations and techniques commonly used when working with numerical datasets in Python.

## Topics Covered

- 1D, 2D, and 3D NumPy arrays
- Array dimensions, shape, size, and data types
- Indexing and slicing
- Reshaping arrays
- Array generation using `zeros()`, `ones()`, `arange()`, and `linspace()`
- Mathematical and vectorized operations
- Boolean masking and filtering
- Broadcasting
- Aggregate functions: `sum()`, `mean()`, `min()`, `max()`, and `median()`
- A combined numerical analysis example

## Summary

The notebook provides a practical introduction to NumPy's core capabilities for handling and analyzing numerical data. The examples demonstrate how NumPy makes array-based calculations efficient, concise, and suitable for data-analysis workflows.
